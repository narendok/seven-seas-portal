# Checklist document automation register

Source: `C:\Users\Test\Downloads\Smart Company document management system audit checklist .xlsx`. Original workbook unchanged. Inventory: 146 source rows, not 146 unique templates or mandatory client deliverables. Sheet/row references preserve duplicates and project variants.

G = Template-generated editable draft. H = Evidence/data-backed editable draft plus real human/tool evidence. U = Upload original; portal generates metadata/cover/index only. These are feasibility proposals, not completed generator status.

Every G/H row needs its actual approved template or a separately approved replacement layout; this checklist supplies names/formats only. Final Admin approval binds the exact revision. Only explicitly released, recipient-authorized PDF renditions become client-visible. Internal confidential rows are not client deliverables by default.

## Confirmed reusable upload types

VTU and XLC are example product/project names, not document types. The workbook spells one example VCU; that raw spelling is retained only for source traceability. Use the selected project ID/name as metadata; do not create a new template or upload type for each product. The seven U rows below are raw inventory occurrences, not the total number of upload types.
